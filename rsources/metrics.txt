# Performance Strategy (Critical)

Most founders destroy performance with Three.js.

Google Analytics, SEO, Core Web Vitals, and conversions suffer.

Rules:

### Only One WebGL Canvas

Never create multiple Three.js canvases.

---

### Lazy Load Everything

```js
dynamic(() => import("./HeroScene"))
```

---

### LOD (Level Of Detail)

Far objects use fewer polygons.

---

### Mobile Fallback

Do NOT render full 3D scenes on mobile.

Use:

* videos
* compressed animations
* lightweight particles

---

### Image Optimization

Use:

```txt
AVIF
WebP
Next Image
```

---

### Target Metrics

Aim for:

```txt
LCP < 2.5s
CLS < 0.1
INP < 200ms
Performance > 90
SEO > 95
Accessibility > 95
Best Practices > 95
```
